# Своє · Промосайт B — мобільна інтерактивна альтернатива

**Статус:** окрема робоча гілка `svoye-mobile-v2`, скопійована з `main` 14.10.2026. **Перший інтерактивний варіант B реалізовано у коді; друга вебадреса ще не розгорнута.** Жодного merge до `main` без окремого узгодження.
**Мета:** мати дві повноцінні версії промосайту для паралельного порівняння. A = оригінальна `main` (не змінювати), B = мобільний інтерактивний продукт у цій гілці.

## Правила ізоляції

1. Розробка B: коміти **тільки в `svoye-mobile-v2`**. Не змінювати `main`, поточну адресу https://svoye-career-path.vasil-rybiy.chatgpt.site чи чинні production-процеси n8n/Neon/Google Calendar.
2. Окрема **адреса/проєкт хостингу** для B. Наявність GitHub-гілки **не є розгортанням сайту**. Перед реальним preview узгодити платформу, перевірити домен та налаштувати deploy **тільки з B-гілки**. Відсутність автоматичного деплою з гілки — очікуваний стан, поки хостинг не під'єднаний.
3. Обмін даними з Telegram — окрема етапна задача. До погодженої інтеграції не вигадувати ім'я бота або deep link, не передавати приватні відповіді в URL, не вважати текст скопійованим = текст надіслано.
4. Контент, бренд-стратегію і юридичні сторінки переважно **перевикористовуємо**, але кожен новий публічний CTA мусить бути робочим або чесно позначеним як недоступний.
5. Два реальних незалежних Telegram-акаунти залишаються критичним P0 до відкриття бронювання для всіх; експерименти з сайтом не змінюють allowlist ботів.

## Продуктова концепція B

- Перший екран: оригінальне лого «своє.» й кольори: `#F6F5F0` фон, `#111B28` текст, `#173DEB` синій, `#D7F26C` лайм, `#FF8E36` помаранчевий. Основний меседж із бренд-платформи: «Знайди свій напрям. Перевір у дії.» Конкретизація: «Ким стати? Куди вступати після школи?».
- Два окремих шляхи «Я школяр/-ка» й «Я з батьків». Для школяра на першому екрані три картки: **Досліджувати / Створювати / Допомагати**.
- Дев'ять реальних проб із `lib/micro-trials.ts` (3 для кожного напряму) — не дублювати описів без причини. Задача = **завершена одиниця смислу**, разом на одному етапі: мета, матеріали, три кроки, результат. Не потрібно перемикати сторінки заради відсутнього пояснення.
- Рефлексія = три окремі смислові етапи на тому самому маршруті. **Вісім шкал загалом:** 3 «що зачепило», 3 «як зі складнощами», 2 «що далі». Повзунок містить іконку, а колір змінюється плавно зі значенням; не фарбувати складнощі як «добре/погано»; `prefers-reduced-motion`, клавіатура, доступні тексти. Дозволяти «Не було» та не вимагати оцінки вигаданих активностей.
- На кожному етапі коротко повторити **назву і мету задачі**, уникати потреби тримати попередній екран у пам'яті. Без декоративної рамки телефона, без внутрішньої прокрутки.
- Підсумок як власне спостереження й наступний крок, а не діагностика здібностей чи обіцянка вступу. Фінальна кнопка «Розібрати в Telegram» — після узгодженої безпечної передачі контексту через одноразовий код та добровільну дію клієнта.
- Другорядні сторінки (про підхід, батьків, засновника, статті, FAQ, політика даних) доступні через меню й не перевантажують перший екран.

## Порівняння A / B перед вибором

Тестувати на телефоні шириною 360/390 px та десктопі; окремі люди з аудиторій школярів і батьків. Фіксувати:
- чи розуміють за 5–10 секунд: це про вибір професії й вступ після школи;
- чи знаходять свій шлях і можуть виконати пробу без втрати контексту;
- чи розуміють повзунки, відсутність оцінки особистості, підсумок;
- чи завершують маршрут, хочуть продовжити розмову, знаходять контакт;
- чи читається все без дрібних шрифтів та непередбачуваного горизонтального скролу.

**Рішення A/B** ухвалити після підтвердженого мобільного тесту та окремого обговорення, не автоматичним merge.
