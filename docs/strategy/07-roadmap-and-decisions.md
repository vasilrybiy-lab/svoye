## 2. Пріоритети наступних етапів

### Найближчі 2 тижні — точність продукту і зворотний зв'язок

- [ ] Зафіксувати стандартну картку послуги: тривалість, результати, межі, ціна, терміни, роль батьків.
- [ ] Провести незалежні інтерв'ю з першими родинами й розділити покупки, усвідомлення та практичні дії.
- [ ] Перевірити мобільний шлях нової родини до прямого контакту/запису; вирішити невідповідність тексту на головній.
- [ ] З партнером узгодити роль розвитку спільноти, формат зустрічей і перший список типів зовнішніх партнерів.
- [ ] Підготувати знеособлений зразок результату з чіткими межами тверджень.

### Наступні 3–6 тижнів — перевірка попиту й малого Lab

- [ ] Залучати наступних клієнтів із вимірюваним джерелом звернення (особисті рекомендації, батьківські спільноти, партнерства).
- [ ] Окремо запросити охочих до **необов'язкового** Lab-пілоту після завершення дослідницьких інтерв'ю.
- [ ] Протестувати один цикл навчальної проби на вигаданих даних; не будувати повний кабінет.
- [ ] Порахувати реальний час наставництва й умови оплати продуктивної праці.
- [ ] Отримати мінімум одну перевірену партнерську задачу з призначеним дорослим наставником.

### 7–12 тижнів — рішення про масштабування

- [ ] За результатами інтерв'ю уточнити обіцянку та сторінку результату.
- [ ] За результатами Lab вирішити: повторити, змінити або призупинити формат.
- [ ] Лише після оцінки попиту й безпеки — ТЗ мінімального кабінету, структури даних та доступів.
- [ ] Після готової воронки — тест малого платного просування.
- [ ] Узгодити партнерську й фінансову модель на наступний квартал.

Це орієнтири, а не твердження, що задачі завершені.

## 3. Гейти рішень

| Перехід | Потрібні умови |
| --- | --- |
| До системного продажу | Ясний офер + дієвий контакт + межі результату + порядок згоди |
| До публічних відгуків | Добровільний дозвіл + безпечне знеособлення + перевірка цитат |
| До Lab | Вільна згода + посильні задачі + наставник + правила винагороди/прав |
| До клієнтського кабінету | Підтверджена корисність + мінімальна модель даних + privacy review + контроль доступів |
| До платної реклами | Працююча воронка + базова аналітика + зрозумілий продукт |

## 5. Відкриті рішення

- Хто юридично відповідає за проєкт, договірні відносини, оплату та використання створених матеріалів?
- Яка форма партнерства між дорослими учасниками, їхні повноваження та права?
- Який базовий офер/ціна/терміни після аналізу собівартості й інтерв'ю?
- Який мінімальний формат підтримки після консультації насправді потрібен?
- Коли виправдано створювати кабінет і що в ньому зберігати?

**Як оновлювати журнал:** дата + джерело факту + формулювання рішення + відповідальний + наслідки для 01–06/08; не стирати старе рішення без історії змін у Git.
